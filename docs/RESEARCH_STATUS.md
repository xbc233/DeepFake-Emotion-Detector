# 研究进展（2026-10-27）

研究方向：基于跨模态不一致性的深度合成诈骗视频检测。当前已完成深伪基础实验、模拟视频制作与初审、固定模型评分和语义错误分析；尚未验证有效的三模态诈骗检测方法。

## 已完成

- LAV-DF选取480段：训练320、验证80、测试80，按来源组隔离；人物身份隔离未验证。
- 提取人脸、语音、文字情感并进行时间对齐；当前JS差异只比较人脸与语音共同情感类别，文字不计入JS。
- 训练轻量基线、引入SyncNet并改善轨迹质量；冻结模型和阈值后开展首次测试。
- 制作48段研究模拟重配音视频，40段完成单人初审；13段定向复核和新增8段人工判断待补齐。
- 48段特征和转写提取完成，44段同步可评分、4段质量拒绝；46段转写与脚本归一化完全匹配。
- 固定本地零样本语义基线，对已知配音文本和转写分别评分；完成误判诊断。

## 结果与限制

| 实验 | 结果 | 解释 |
|---|---|---|
| LAV-DF首次测试 | 有效76/80，AUC 0.7932，召回49.12%，误报10.53% | 同步线索有一定区分能力，仍不满足部署要求 |
| 模拟视频情感差异 | 初审关系明确35段，AUC 0.5161 | 未显示明显区分能力，仅4段人工判为一致 |
| 模拟诈骗语义 | 明确初审36段，脚本AUC 0.5276、转写AUC 0.5016 | 当前通用零样本基线效果不足 |

所有模拟视频均替换了合成配音；普通话术不等于真实未合成视频。没有换脸、声音身份克隆或口型重动画，不能用此批计算真假分类误报率或证明真实诈骗检测效果。人工标签未用模型预测填补。

19条语义误判中，13条原文本已误判，4条涉及初审/制作预设分歧，2条由转写改变阈值判断。分组是排查顺序，不是已证实因果。

## 未完成与下一步

- 补齐定向复核和新增样本的人工标签，不用制作意图代替情感真值。
- 规划独立模拟语义试点：60个模板族、120条文本，按族72/24/24划分训练/验证/测试。尚未制作或训练，设计标签也不能直接充当人工测试真值。
- 建立轻量语义分类基线，使用独立数据评估，再考虑融合；现有48段已查看，仅供开发。
- FakeAVCeleb仍待获批；拟用于深伪跨数据集验证，不能补诈骗语义真值。
- 已看过的LAV-DF测试结果不能继续作为改法后的未见测试。
