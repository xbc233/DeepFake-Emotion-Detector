# 冻结方案与首次独立测试

2026-10-25完成。模型与阈值在测试特征提取前冻结，测试结束后未修改参数。此目标完整结束。

## 冻结方案

采用上一轮验证AUC最高的仅同步逻辑回归模型，不重新拟合。输入为最小距离、零偏移距离、同步置信度和绝对偏移；沿用训练集填补、标准化及固定轨迹规则。

阈值选择只读取验证集：在观测误报率不超过10%的候选中最大化召回率；并列时优先低误报，再取高阈值。10%是本轮预先声明的探索性标准，不是用户给出的部署指标。最终阈值 **0.8677991035074184**，验证误报2/20=10%，召回37/60=61.67%。仅20段真实验证视频，不能保证总体或测试误报率不超过10%。

frozen_protocol.json记录UTC冻结时间、模型哈希、验证分数哈希及处理代码哈希；frozen_model.json保存模型副本。提取程序不读取测试真假标签，全部提取结束后才进行标签对照。测试样本源组与训练/验证无交集，但人物身份隔离未验证。

## 测试覆盖

80段、20来源组全部处理，无运行失败。76段有效（95%），4段质量拒绝：真实1段、伪造3段。有效真实19段、伪造57段。拒绝样本不被填为零分或归为真实。

## 固定阈值下的测试结果

| 指标 | 数值 |
| --- | ---: |
| ROC-AUC（有效样本） | 0.7932 |
| AP（有效样本） | 0.9186 |
| 真阳性 TP | 28 |
| 假阳性 FP | 2 |
| 假阴性 FN | 29 |
| 真阴性 TN | 17 |
| 召回率（有效伪造） | 28/57 = 49.12% |
| 误报率（有效真实） | 2/19 = 10.53% |
| 精确率（有效告警） | 28/30 = 93.33% |
| 全部伪造样本告警比例，含拒绝评分 | 28/60 = 46.67% |

有效样本伪造比例75%，AP的阳性比例参考值为0.75。93.33%的精确率也依赖此人工样本比例，不代表真实业务中的告警准确度。模型输出未经概率校准。

按20个来源组进行2000次bootstrap，固定种子20261025：AUC描述性95%区间[0.7257,0.9031]，召回[0.3122,0.6667]，误报[0,0.2632]。区间仅反映此样本的来源组重采样，不涵盖人物身份关联、预训练数据重叠、模型选择过程或新场景漂移。

## 判断

冻结同步方案在这批首次测试中表现出一定真假排序能力，但约10%的误报水平下仅检出一半左右可评分伪造视频，且5%视频不能评分。不能称为满足部署要求，也不能声称“低误报高召回”。测试观测误报10.53%并未满足字面上的不超过10%，没有为了满足目标回调阈值。

该结论针对LAV-DF深度合成检测，不涉及诈骗标签。情感辅助特征此前未确认稳定增益，本次未将其纳入最终模型。不能据此宣称完成了三模态诈骗视频检测。

## 后续边界

本测试集已被查看，从此不能继续作为新版本的未见评测集。后续可做错误归因及诈骗语义模块研究，但如果据此改模型或阈值，需使用新的封存样本或外部数据集报告泛化效果。已有报告可以作为本次冻结版本的历史结果保存。
